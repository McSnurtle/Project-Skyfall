## NOTICE:
This is the experimental bobby version of the modpack. It will receive updates *after* the main, stable DH (Distant Horizons) verison of the modpack as found in the main branch. This version uses a chunk caching approach which locally stores chunk data from the server directly, instead of using LoDs. Use this version if it gives you more FPS and doesn't crash!! Note: shader support is buggy and experimental on this version.

# Project-Skyfall
The Minecraft server nobody asked for, but everybody needs. Factorio, Frostpunk, Stardew Valley, and all the good of Minecraft, all in one.
Originally intended to be a brutal, 1:1 earth-scale factory planning, city planning, logistics nightmare (structural integrity was even considered!), turned into a beautiful clash of exploration, territory expansion, diplomatic relations, and of course city management.
