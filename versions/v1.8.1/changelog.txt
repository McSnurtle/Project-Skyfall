**Gameplay Changes**
 - Added new connected textures resourcepack (`Connected Texture+ V4.zip`) ([Repo](<>), [Curseforge](<https://www.curseforge.com/minecraft/texture-packs/connected-texture/download/6079335>)) (#350 by @brousmelly )
 - Added recipes for the new recruit blocks (all recipes use any type of (vanilla) planks or sword, they must be full durability. Only the vanilla bow is allowed. Any shields registered as <tag:items:forge:shields> will work for the shieldman table, but only vanilla shields are tested):

 - Removed the anti-xray mod, increasing client-side performance - feel free to try x-raying, but good luck with it! (#136 by @brousmelly )
 - Removed the "underworld" mechanic where players would be transferred to and from the nether by touching bedrock (#336 by @McSnurtle )
 - Saplings will now despawn when left on the ground instead of trying to plant themselves (#335 by everybody)
 - Added a client-side mod to optimize systems with low memory capacity (`mods/alltheleaks-0.1.0-beta+1.20.1-forge.jar`) ([Repo](<>), [Curseforge](<https://www.curseforge.com/minecraft/mc-mods/alltheleaks/files/5936734>))
 - Slightly reduced the minimum colony creation distance
 - Reduced the server-side simulation distance to 5 to increase tps. This means that only chunks within a 5 chunk radius around you will be loaded at any given time! (#345 by @IAmNotYou4Real )
 - Reduced the server-side view distance to 12 in an effort to increase tps. This means that without the use of the included client-side view distance enhancement mods like bobby, acedium, or distant horizons, you will only be able to see a maximum of 12 chunks around you in all directions. (#345 by @IAmNotYou4Real )
 - Removed the recipe for gravitrons - note that pre-existing gravitrons will remain, feel free to scalp them on ebay! (#351 by @McSnurtle )
